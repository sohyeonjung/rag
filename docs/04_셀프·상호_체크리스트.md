## 2. 상호 체크리스트 (옆 교육생과 교환)

점검자: ______________ · 점검일: ______________

| 확인 항목 | 결과 (통과/실패/미확인) | 메모 |
| --- | --- | --- |
| 기업을 골라 질문하면 근거 번호가 달린 답변과 근거 목록이 나온다 | | |
| 문서에 없는 질문에 "확인되지 않습니다"라고 답한다 | | |
| 투자 판단 질문을 거절하고 면책 문구가 보인다 | | |
| 기업을 바꾸면 이전 대화가 섞이지 않는다 | | |
| 조건으로 기업 찾기 결과가 조건에 맞는다 | | |
| 브리핑 카드 · 팩트체크 · 용어 풀이 결과에 근거가 있다 | | |
| 첫 질문 때 진행 상태가 보인다 | | |
| 근거 목록에 출처 종류(기업정보 · 위키백과 · DART 공시 · 한국은행 용어집)가 구분된다 | | |
| 다른 기업을 묻거나 잡담하면 답하지 않고 안내한다 | | |
| 화면에 API 키 · 프롬프트 · 오류 추적 정보가 보이지 않는다 | | |
