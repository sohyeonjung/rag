# 요구사항 정의서 — FinRAG: 근거로 답하는 상장기업 리서치

> AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스

## 1. 서비스 개요

코스피 시가총액 상위 100개 기업에 대한 질문을 **공개 문서(한국어 위키백과 · DART 공시 · 한국은행 경제금융용어 800선)** 를 근거로만 답하고,
답변에 실제로 인용한 근거의 제목과 원문 출처를 함께 보여 주는 RAG 서비스다.

기업 정보는 숫자·날짜·지배구조처럼 LLM이 그럴듯하게 지어내기 쉬운 사실이 많고, 틀리면 투자 판단을 그르칠 수 있다.
그래서 "근거가 없으면 확인되지 않는다고 답한다"를 서비스의 핵심 원칙으로 삼았다.

## 2. 도메인 선택 조건 충족 근거

| 조건 | 충족 근거 |
| --- | --- |
| 항목 메타데이터 약 100건 이상 | 코스피 시가총액 상위 **100개 보통주** (2026-10-20 기준). 순위는 공공데이터포털 금융위원회_주식시세정보로 정하고, 속성은 **OpenDART 기업개황 API로 100/100건** 확보 — 정식명칭·영문명·대표자·설립일·결산월·본사 주소·업종코드. 위키백과 도입부 요약 1~2문장을 개요로 더함 |
| 외부 문서 출처와 이용 조건 | ① 한국어 위키백과 — CC BY-SA 4.0, 100개 기업 모두 기업 문서 매핑 완료 ② DART 정기보고서 — 금융감독원 공공정보 ③ 한국은행 「경제금융용어 800선」(2026) — 저작권 한국은행, 원본 미배포·출처 표시 ④ KRX 시세(순위 선정용) — 공공누리 4유형, 원본 미배포 |
| 근거 없이 답하면 틀리거나 위험한 질문 | 아래 2.1 — 근거 없이 같은 모델(gpt-4.1)에 물었을 때 9개 중 2개를 지어냈다 (F2015 비교) |
| 위험 도메인 여부 | **해당 (금융)** — 면책 문구를 화면에 상시 표시하고, 매수·매도·주가 전망 질문은 답변 프롬프트에서 거절한다 |

### 2.1 근거가 필요한 질문 (대표 질문)

| 질문 | 근거 없이 답했을 때 | 정답과 근거 |
| --- | --- | --- |
| SK하이닉스는 언제, 어떤 이름의 회사로 처음 설립됐나? | "1983년 현대전자산업" (오답) | 1949년 국도건설 — 위키백과 연혁 · DART 설립일 |
| 삼성전자의 2026년 반기 DS 부문 매출은 얼마야? | "알 수 없다" | 209조 2,317억원 — DART 반기보고서(2026.06) |
| 기아의 현재 대표이사는 누구야? | "송호성" (일부만) | 송호성 · 송민수(각자 대표) — DART 기업개황 |
| 네이버의 2030년 매출 전망은 얼마야? | "20~30조 원대" (지어냄) | 어느 문서에도 없음 → "확인되지 않습니다" |
| 기아 주가 오를 거라던데 지금 사야 돼? | — | 투자 판단 → 거절하고 확인된 사실만 제시 |

### 2.2 면책 문구

> 본 서비스는 공개된 문서를 근거로 정보를 제공하며, 투자 권유나 투자 자문이 아닙니다. 문서의 기준일 이후 바뀐 내용은 반영되지 않을 수 있으며, 투자 판단과 책임은 이용자에게 있습니다.
